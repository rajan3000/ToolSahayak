How to Compress PDF?

  • Select one or multiple PDF files.
  • Choose Low, Recommended or High Compression.
  • Optionally enter your target PDF size in KB or MB.
  • Click Compress PDF Files.
  • Download each compressed PDF separately.

Important Note

This tool recreates PDF pages as compressed images. Selectable text, links, forms, bookmarks and some interactive PDF features may not be preserved. Target size is an approximate goal, not a guaranteed exact size. If the target cannot be reached, the tool provides the smallest result it could generate using its available compression attempts.
