Frequently Asked Questions

1. What is a Text to Icon Maker?

A Text to Icon Maker converts letters, words, initials, numbers and emojis into custom graphical icons.

2. Can I create a favicon for my website?

Yes. Select 16 × 16 or 32 × 32 pixels to create a favicon. You can also copy the generated favicon HTML code.

3. Which download sizes are available?

You can create PNG icons in 16, 32, 48, 64, 128, 180, 192, 256 and 512 pixel square sizes.

4. Can I use a transparent background?

Yes. Enable Transparent Background to create a PNG icon without a background.

5. Is this tool free?

Yes. Toolaxa Text to Icon Maker is free to use and processes your design in your browser.
