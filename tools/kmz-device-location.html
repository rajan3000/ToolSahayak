What is a KMZ File?

KMZ is a compressed file format used by Google Earth. It contains geographic information in KML format, including points, names and descriptions. This tool helps you create a device location map without manually preparing KML files.

Supported Device Examples

CCTV cameras, ANPR cameras, RFID readers, UHF antennas, VMS displays, Electronic Control Boxes (ECB), UPS systems, WIM sensors, traffic signals, network switches, routers, servers, barriers and other infrastructure equipment.

Frequently Asked Questions

Is this KMZ generator free?

Yes. The tool can be used free in your browser. Map tiles and external libraries require an internet connection.

Can I open the exported KMZ file in Google Earth?

Yes. Download the KMZ file and open it in Google Earth or Google Earth Pro.

Where is my device data saved?

Device records are saved in your browser's local storage on the current device and browser.

Can I export device locations to Excel?

Use Export CSV. The CSV file can be opened in Microsoft Excel and other spreadsheet applications.
