How to Merge PDF Files?

  1. Select or drag and drop two or more PDF files.
  2. Use the up and down arrows to arrange the PDF order.
  3. Remove any unwanted PDF file if required.
  4. Enter your preferred output file name.
  5. Click on Merge PDF & Download.
  6. Your combined PDF will be downloaded to your device.

Frequently Asked Questions

Is this PDF merger free?

Yes. You can merge PDF files using this tool without registration or payment.

Are my PDF files uploaded?

No. The merging process runs in your browser. The PDF files are not sent to our server. The PDF processing library is loaded from an external CDN.

Can I change the order of PDF files?

Yes. Use the up and down buttons next to each file to arrange the order before merging.

Can I merge more than two PDFs?

Yes. You can select multiple PDF files and combine them into one document, subject to your device's available memory.

Does this tool work on mobile?

Yes. The page is designed for desktop, tablet and mobile browsers.
